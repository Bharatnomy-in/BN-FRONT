# Maharashtra: district data

District-level tables for Maharashtra, organised by Bharatnomy's lenses. Generated by `build.py`; do not edit.

- **Datasets:** 28
- **Data as of:** 2026-10 (latest observed period across datasets, projections excluded; each table has its own period)
- **Warehouse commit:** [`41650b8bb197`](https://github.com/sarveshkant2003-afk/bharatnomy-data/tree/41650b8bb1975a4f4e082ba172d8b5dfb8f7db8a)

## Files for maps

- [`district-profile.csv`](district-profile.csv) / [`.json`](district-profile.json): one row per district (20 indicators, each with a `_year` column saying which year was used). Empty = no value, never zero.
- [`districts.geojson`](districts.geojson): district boundaries (Census 2011, DataMeet), joined on `lgd_district_code`.
  - **Palghar** (`665`) was created after 2011 and has no boundary yet (`geometry: null`); its area is inside its parent district's 2011 polygon.

## How to use

- Join tables to each other and to the map on **`lgd_district_code`** (text), not on district names.
- Every dataset folder has a CSV, a JSON (array of row objects; codes are strings, numbers are numbers, missing = `null`) and a README with sources and column meanings.
- Raw-file URLs (for code or direct download):

```
https://raw.githubusercontent.com/sarveshkant2003-afk/bharatnomy-front/main/states/maharashtra/district-profile.csv
```
