# Power plant generation by plant and year, 2013 to 2019 — Maharashtra

Electricity generated by each plant in the WRI Global Power Plant Database, reported (from CEA, 2013-2019) and estimated by WRI's models (2013-2017), in GWh.

## Coverage

- **Rows:** 595
- **Period:** 2013 to 2018
- **Note:** The warehouse table covers 2013-to-2019; this state's rows cover 2013-to-2018.
- **Districts:** 28 of 36

## Source

- **Data:** World Resources Institute (WRI), Global Power Plant Database v1.3.0 (June 2021), CC BY 4.0
- **Table taken from:** `global_power_plant_database.csv`, India rows, columns `generation_gwh_<year>`, `estimated_generation_gwh_<year>`, `estimated_generation_note_<year>`, reshaped to one row per plant per year
- **Link:** https://datasets.wri.org/dataset/globalpowerplantdatabase
- **Downloaded:** 24 Nov 2026
- **Script:** [`pipelines/wri-gppd/build_power_plants.py`](https://github.com/sarveshkant2003-afk/bharatnomy-data/tree/41650b8bb1975a4f4e082ba172d8b5dfb8f7db8a/pipelines/wri-gppd/build_power_plants.py)

## Notes from the warehouse

These describe the full warehouse table (all states).

- A plant-year is listed only if the source has a reported or an estimated value. Blank cells are blank in the source (no reason given).
- WRI estimates only to 2017; reported figures run to 2019.
- Checks (24 Nov 2026): no duplicate plant-years; values non-negative.
